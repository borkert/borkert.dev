01 / Featured work

APICAT · API TOOLING FOR HUMANS + AGENTS
digplan / apicat

APIs as executable definitions.

apicat keeps API definitions in YAML and turns them into a tiny CLI and JavaScript library. List an API, inspect it, call it, or hand the definitions to an LLM.

The idea is deliberately simple: instead of teaching an agent dozens of bespoke integrations, give it a compact, machine-readable vocabulary for making HTTP and WebSocket calls.

YAMLCLIJavaScriptHTTPWebSocketLLM TOOLING
github.com/digplan/apicat →
$ npm install -g apicat

$ apic ls
httpbin.get
openai.chat
openrouter.chat
cloudflare.r2Upload

$ apic openrouter.chat \
  MODEL=openrouter/auto \
  PROMPT="Say hello"

→ request built from YAML definition
→ response extracted / returned
